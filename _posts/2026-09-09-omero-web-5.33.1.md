On September 9, we released OMERO.web 5.33.1, which includes 
a fix for a security vulnerability, see 
[GHSA-jhrq-7mrq-96j8](https://github.com/ome/omero-web/security/advisories/GHSA-jhrq-7mrq-96j8)
for more details.

Please see the [OMERO.web release](https://github.com/ome/omero-web/releases/tag/v5.33.1)
and [notes on upgrading](https://github.com/ome/omero-web/blob/v5.33.1/UPGRADING.md).


### Installing the Software

OMERO.web 5.33.1 is available from PyPI - see 
[here](https://pypi.org/project/omero-web/5.33.1/).

Official Docker images are available as usual on Docker Hub with either
the latest or the 5.33.1 tag:

* <https://hub.docker.com/r/openmicroscopy/omero-web-standalone>
* <https://hub.docker.com/r/openmicroscopy/omero-web>

Please note that the Docker images are now based on [Rocky Linux 9](https://rockylinux.org/) to
support the latest OMERO.web releases.

You are invited to discuss this announcement on
[the image.sc forum](https://forum.image.sc/tags/c/data-management/29/omero).

All the best with your upgrades,

The OME Team
